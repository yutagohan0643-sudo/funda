## レポートの形（毎回この順）

1. **今日のひとこと** — 3〜5行で一番大事な動き
2. **会社ごと** — 市場動向（業績・受注・新製品・組織・人事・提携）と小さな話題。前回から何が変わったか
3. **機器全体の市場動向（会社に直接関係なくても）** — 機器の種類ごとに、業界全体・同業他社・統計・制度の動き。最後に「強い／弱い／共通の困りごと」のまとめ
   - 電子部品・基板・部材（JEITA・経産省の統計、メモリ・半導体の価格、為替）
   - 船舶・海の機器（新造船の受注、古野電気など同業、レーダー・衛星通信）
   - 防災・自治体・公共の無線（防災無線・消防無線・公共安全LTE・予算や交付税）
   - 放送・映像機器（放送局の設備投資・マスター集約・IP化、ソニー・パナソニック・キヤノンなど）
   - 光通信・伝送（データセンター・鉄道・電力、フジクラ・古河電工など）
   - 電力・スマートメーター
   - 医療機器・超音波（GE・フィリップス・シーメンス・キヤノンメディカル、病院経営、診療報酬）
4. **お客さんとの話題（業界ネタ）** — 会社ごとに「こう聞くと話が広がる」形の一言
5. **お客さんとの話題（業界以外）** — 季節・天気・スポーツ・エンタメ・旅行・食・世の中の話題。誰とでも話せる軽いもの。政治・宗教など分かれやすい話題は「事実だけ・深入りしない」の注意つき
6. **今後の予定** — 決算日・展示会・イベント
7. **出典**

- 小さなニュースも拾う。日付を必ず確かめ、まとめ記事・掲示板だけの情報は「未確認」と書く
- 推定は「推定」と書く
