# sride — 日本株ファンダメンタルズ・スクリーナー

東証上場の小型株を**割安度・質・成長性のファンダメンタルズ**で順位付けします。
`--mode undiscovered` で、アナリストや機関投資家にまだ見つかっていない銘柄を優先するモードにも切り替えられます。

## 使い方

```bash
cd screener
pip install -r requirements.txt
python -m sride                         # ファンダのみでスコア (既定)
python -m sride --mode undiscovered     # 未発掘度を加味 (アナリスト ≤ 2人)
python -m sride --max-mcap 300 --max-per 15 --markets スタンダード,グロース
python -m sride --help
```

出力: `screener/reports/YYYY-MM-DD/<mode>/report.md`(上位銘柄表)と `candidates.csv`(通過全銘柄・全指標)。
詳細データは `cache/` に24時間キャッシュされます。

必要な通信先: `www.jpx.co.jp`, `query1/query2.finance.yahoo.com`, `fc.yahoo.com`, `guce.yahoo.com`

## 仕組み

1. **ユニバース**: JPX 上場銘柄一覧(プライム/スタンダード/グロースの内国株)
2. **一次フィルタ**(Yahoo バルクスクリーナー): 時価総額 20〜500億円、PER ≤ 20、PBR ≤ 2.5、売買代金 ≥ 500万円/日
3. **二次フィルタ**(個別詳細): ROE ≥ 8%、金融業を除外(undiscovered モードはアナリスト ≤ 2人も)
4. **スコア**(各指標の順位パーセンタイル, 0〜100)

| 要素 | fundamental (既定) | undiscovered | 指標 |
|---|---|---|---|
| 割安度 | 35% | 25% | 現金調整PER↓、PBR↓、EV/EBITDA↓、純現金/時価総額↑ |
| 質 | 40% | 25% | ROE↑、ROA↑、営業利益率↑、流動比率↑、純現金↑、インサイダー保有↑ |
| 成長 | 25% | 15% | 売上成長率↑、利益成長率↑ |
| 未発掘度 | — | 35% | アナリスト数↓、機関保有比率↓、時価総額↓、売買代金↓ |

**現金調整PER** = PER × (1 − 純現金/時価総額)。日本の小型株に多い「現金過多で PER が実態より高く見える」銘柄を拾うための指標です。

### 自動の注意フラグ
- `⚠特益?` 純利益率が営業利益率を大きく上回る → 特別利益で PER が低く見えている可能性(−15%)
- `⚠データ` 時価総額÷純利益と表示 PER が乖離 → Yahoo のデータ不整合の可能性(−30%)

## 限界
- Yahoo Finance の日本小型株データは欠損・誤りがあります(アナリスト数や機関保有比率の多くは 0 扱い)。
- 直近四半期の業績や特別損益は反映が遅れることがあります。**最終判断は決算短信・有価証券報告書で確認してください。**
- 投資助言ではありません。
