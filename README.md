新しい銘柄の候補を、ファンダ（直近の開示）とテクニカル（売られすぎ）の両方から探すリポジトリ。

**毎週土曜 6:30（日本時間）に自動で更新**（GitHub Actions。スクリーナーと候補探しの機械的な一覧）。人が評価を書く `_次の決算.md`・`_材料.md` は手で作る。

## 監視銘柄に上げる（昇格）

- 売られすぎランキングから、**不当な下げ・総合65点以上・増益か黒字転換・PER 15倍未満・信用買残が上場株数の10%未満**をすべて満たす銘柄を [昇格候補](screener/昇格候補.md) に自動で出す（最大10銘柄）
- 昇格候補か、ファンダの候補の ◎ から選ぶ → TDnet で下げた理由・材料・新株予約権を確かめる → trade リポジトリの `funda/` で基礎分析を作り表に足す（信用残ウォッチに自動で入る）→ trade の割安判定に足して採点
- **割安判定 60点以上なら監視を続け、45点未満なら監視から外す**

## ファンダの未発掘銘柄探し

- `python tools/candidates.py`（直近21日の TDnet の開示 → `candidates/YYYY-MM-DD.md`。TDnet に残っているのは約1か月分なので `--days 31` まで）
- 一覧の上位は本文を読み、`candidates/YYYY-MM-DD_次の決算.md`（A 勝率ランキング・B 決算・C 割安で放置）と `_材料.md`（直近3営業日・D 企業再評価・E 大きな材料）に人の頭で評価を書く。A〜E の測り方は各ファイルの冒頭
- 新しい候補ファイルを作ったら、上の表のリンクを差し替える

## テクニカルの未発掘銘柄探し（売られすぎスクリーナー）

- 全銘柄（JPX の信用残データに載っている約3,750銘柄。ETF・REIT・インフラファンド、売買代金が1日平均1,000万円未満の銘柄は除く）から、日足の安値がボリンジャーバンド（20日）の -3σ にタッチした銘柄を「下げすぎ」として拾う。-2σ にタッチしたが -3σ には届かなかった銘柄は予備軍として別のファイルに出す
- **外す銘柄（致命的なファンダ）**: 債務超過／資金繰り（赤字で、現金が赤字の8四半期分未満）／株数が1年で+10%以上の希薄化／売上が前年同期比-30%以下／営業赤字が1年続き拡大中。致命的ではない気になる点は「懸念」として出す
- **更新**: 毎週土曜に自動。手元では `python -m screener`（1時間前後。決算データは7日間使い回すので2回目からは速い）。対象の銘柄一覧は JPX の最新の信用残データを取って `data/margin/daily/` に保存して使う
  - `--sub-sigma 0`: -3σ だけ出す（速い）・`--days 5`: 直近5営業日のタッチを拾う・`--sigma 2.5`: 基準の σ を変える
- 基準値は `screener/core.py` の上の方。過去の結果は `data/screener/`
- 下げた理由（悪材料）は決算データでは見えないので、TDnet の適時開示で必ず確認する

