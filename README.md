# ファンダ分析（推論のしかた）

チャート・需給（信用残）とは別に、**会社の中身だけ**から「この株価は何を織り込んでいて、どこが崩れると困るか」を考える。
下の信用残ウォッチの「ファンダ」欄は Yahoo Finance の数字を機械的に出すだけなので、ここでは**決算短信・説明資料・適時開示の PDF を読んで**人の頭で推論する。

## 推論の順番（毎回この順に考える）

1. **何で稼いでいるか** — セグメント別の売上・利益・利益率。伸びている事業と縮んでいる事業を分ける
2. **利益の質** — 本業の利益と一回きりの利益（評価益・売却益・売却損）を分ける。「ふつうの年」の利益を作り直す
3. **会社予想の達成しやすさ** — 上期の実績と通期予想から「下期に必要な数字」を逆算し、上期の何倍かを見る
4. **お金の流れ** — 営業CF、前渡金・前受金・在庫など運転資金、現金の残り。利益が出ていても現金が減っていないか
5. **バランスシートの危うさ** — 自己資本比率、借入、のれん、取引先への前払い、顧客から預かっている資産
6. **1株あたりで見る** — 株数の増え方（増資・新株予約権・株式交換）。会社全体の利益が増えても1株利益が増えるとは限らない
7. **値段** — 時価総額 ÷（作り直した利益）＝ PER。似た会社や、会社自身が他社を買ったときの値付けと比べる
8. **シナリオ** — 強気・基本・弱気の3つで「1株利益 × 倍率」を出し、いまの株価がどれに近いかを見る
9. **何を見れば答え合わせできるか** — 次の決算・開示で確かめる数字と日付を決めておく
10. **経営の信頼度** — 計画の達成歴、方針転換の多さ、大株主・経営陣の顔ぶれ

## 銘柄ごとの分析

- **`コード_開示.md`**: 調べられる限りの過去の開示すべての一覧（URL つき）と1件ずつの分析。前半に、開示を通して読んで見えた流れ（年表・業績の推移・資金調達と株数・関係者の地図）

## 候補探し（材料から）

TDnet の全銘柄の開示を読み、**材料そのものの大きさ**で候補を拾う入口（株価の動きは見ない）。上位は本文を読んで評価し、深掘りする銘柄は上の手順で `コード_基礎.md` を作る。

```bash
python tools/candidates.py               # 直近21日の開示 → candidates/YYYY-MM-DD.md（先頭に直近3営業日の開示、各表は【新】）
python tools/candidates.py --days 31 --max-mcap 10000
```

| タイプ | 材料の大きさの測り方 |
|---|---|
| A. 次の決算に向けた候補 | （分析ファイルで人が作る）季節性を差し引いた進捗・予想に必要な残り期間の伸び・伸びの理由・**会社の予想の出し方（過去の上方修正の癖）**・株価の織り込み度 |
| B. 決算・業績が非常に良い | 業績予想の上方修正は XBRL の前回予想→今回予想（営業利益 +10% 以上）。決算短信は営業利益の伸び・通期予想の伸び・**通期予想への進捗**（標準より20ポイント以上先行なら上方修正の余地） |
| C. なぜか割安で放置 | （分析ファイルで人が作る）予想 PER が業種より低いのに利益の中身が良くなっている会社。放置の理由（赤字の記憶・流動性・大株主・借入・市況株扱い）をデータで確かめる |
| D. 企業再評価 | 中計・資本コスト・還元方針・配当方針・事業の組み替え・資本業務提携。自社株買いは**新しく決めたもの**で、発行済株式の2%以上 |
| E. 大きな材料 | 受注・契約・提携・買収・承認など。本文の金額（受注金額・取得価額など）÷ 年間売上 |

- 必要な通信先: `www.release.tdnet.info`、`www.jpx.co.jp`、`query1/query2.finance.yahoo.com`（時価総額だけ）

## 信用残ウォッチ（監視銘柄の信用買残の推移）

監視銘柄の信用買残・売残を、JPX の公式データから毎日自動で記録し、推移のグラフと一覧を更新します。

- **見る場所**: [`margin/README.md`](margin/README.md)（GitHub のアプリやブラウザでそのまま読めます）
- **監視銘柄の変更**: [`watchlist.txt`](watchlist.txt) に「銘柄コード 銘柄名 [関連する米国のテーマ]」を1行ずつ書く（例: `4493 サイバーセキュリティクラウド [サイバーセキュリティ, クラウド]`）。[ ] は省略可。スマホの GitHub アプリからも編集できます
- **更新のタイミング**: 平日 17:30 と 19:17（日本時間）に GitHub Actions が自動で実行
- **データ**: 信用残は JPX「[銘柄別信用取引残高](https://www.jpx.co.jp/markets/statistics-equities/margin/01.html)」（毎営業日16時ごろ公表・前営業日申込み分）、株価は Yahoo Finance

レポートは「地合い」と、銘柄ごとの「ひとこと・チャート図・分析・転換点・ファンダ」で構成。全銘柄のデータを `data/margin/daily/` に保存しているので、あとから監視銘柄を増やしても、保存を始めた日からの推移が見られます。

#### レポートの項目

| 項目 | 意味 |
|---|---|
| 地合い | VIX・米国指数（S&P500・NASDAQ・ダウ・SOX・先物・ラッセル2000）・米10年金利・日経平均（週足13週線）・日経先物・グロース250・TOPIX・原油・ドル円・ビットコインを「追い風／中立／向かい風／注意」で判定。米国の12セクターと35のテーマ・業種（サイバーセキュリティ・量子コンピュータ・宇宙・データセンター・原子力など）の前日比・5日比をランキングのグラフで出す |
| 米国の関連テーマ | watchlist.txt の [ ] に書いたテーマの、前夜の米国での前日比・5日比。±3%以上動いたら注目ポイントにも出す |
| ひとこと | 銘柄ごとに、引力・セクター・表面の評価・上値の重し・下方向の圧力・次の転換点・反発をまとめた自動のコメント |
| 温度感（地合い） | 市場全体の楽観・悲観のものさし。信用評価損益率（JPX の全銘柄の信用残から上位500銘柄で推定、-20%前後で底・-3%前後で天井の目安）と、日経平均のテクニカル（25日・75日乖離、RSI、ボリンジャーバンド、13週線、52週高値から）で、冷えている／普通／熱いを出す。記録は data/market_margin.csv |
| 引力（地合い） | グロース250・日経平均（25日線と5日騰落）、前夜の米国、VIX から、地合いの引力が上向き／横ばい／下向きのどれか。VIX のピークアウトも出す |
| セクター | watchlist.txt で設定した関連テーマ（米国のテーマETF）の前日比・5日比 |
| 表面の評価 | PER・PBR の水準だけで見た割安〜割高の目安（PER 10/20/40倍、赤字なら PBR 1/3/8倍で区切る）。妥当な株価はファンダを見て自分で判断する |
| 上値の重し | MSワラント・新株予約権の行使・公募増資・売出し・第三者割当（転換社債を含む）・大株主の異動の開示（直近1年、IR 材料ランキングの記録から。**IR 材料ランキングは trade リポジトリに残したので、ここでは今は出ない**）、株数の増加（希薄化）、IPO後のロックアップ解除 |
| 新規材料 | IR 材料ランキングが保存した、直近30日の適時開示（**trade リポジトリに残したので、ここでは今は出ない**） |
| 下方向の圧力 | 直近5日の株価・信用買残・出来高のバランスで、下方向の圧力が助長／解放中／弱まる／くすぶる、などを出す |
| 転換点 | エネルギーが発揮されやすい位置の候補（抵抗・支えの根拠から探す） |
| 本尊の気配 | 本尊（主力）が動いたときに残りやすい足跡7つ（出来高の偏り・OBV・地合いへの逆行・下値で止まる・信用売残の増加・大株主の買い集め・大商い後の値持ち）。3つ以上で「あり」。大商いの上ヒゲや出来高を伴う安値割れは「手じまい」として出す |
| 反発サイン | 1日ごとに反発が見られたか。直近3日を ◎強い反発・○反発・△下げ渋り・×反発なし で並べ、グロース250が-1%以下の日の陽線には「逆」（逆行陽線）を付ける |
| 信用買残・売残 | まだ返済されていない信用買い・信用売りの株数と、上場株数に対する比率（JPX の「上場比」）。買残が上場株数の10%以上なら「需給が重い」と注目ポイントに出す |
| ファンダ | PER（直近4四半期の純利益）・PBR・時価総額を最新の株価で計算し、直近四半期を前年同期と比べて評価（増収増益・増収減益・営業黒字転換など。営業利益を重視）。営業赤字・減益・利益率の悪化・株数の増加（希薄化）・負債・資金繰り・割高などの懸念も出す。データは Yahoo Finance の四半期決算 |
| 上値を押さえる要因（チャート以外） | IPO後のロックアップ解除の目安（上場日から90日後・180日後、あと何日か。前後10日に入ったら注目ポイントにも出す）・株数の増加（希薄化）・信用買残が上場株数の10%以上。新株予約権（MSワラント）・転換社債・売出し・大株主の売りは開示で手動確認 |
| 5日前比 | 5営業日前と比べた買残の増減率 |
| 信用倍率 | 買残 ÷ 売残 |
| 平均建値（推定） | JPX が公表する買残の金額 ÷ 株数。信用買いしている人たちの平均の買値の目安 |
| 買い方の損益（推定） | 株価 ÷ 平均建値 − 1。大きなマイナスは、含み損を抱えた買い方が多い目安 |
| 買残÷出来高 | 買残が直近20日の平均出来高の何日分か |
| 抵抗になりやすい位置 | 株価の上で戻り売りが出やすい価格を近い順に3つ。含み損の保有者が厚い価格帯・信用買い方の平均建値・保有者全体の平均コスト・25日／75日移動平均・直近60営業日で跳ね返された高値（その後10営業日以内に5%以上下げたもの）・埋まっていない下落の窓から探し、根拠が重なるほど★が増える |
| 支えになりやすい位置 | 株価の下で買いが入りやすい価格を近い順に3つ。含み益の保有者が厚い価格帯・株価より下にある平均建値／平均コスト・25日／75日移動平均・EMA20・ボリンジャー-2σ・フィボナッチ50%押し・追証ゾーン（直近高値の-10〜20%）・直近半年で反発した安値・埋まっていない上昇の窓から探す |
| 価格帯別の保有者（推定） | 現物も含めた保有者全体が、どの価格帯で買ったかの推定分布。過去2年の株価と出来高から計算するモデル値（moomoo などのコスト分布と同じ考え方）。含み益の保有者の割合、平均コスト、保有者が厚い価格帯も出す |

#### 注意
- JPX のサイトには直近5営業日分しか置かれません。自動更新が5営業日以上止まると、その間のデータは取れなくなります。
- 手元で動かす場合: `pip install -r requirements.txt` のあと `python -m margin_tracker`

> 2026/11/22 に trade リポジトリから移した。IR 材料ランキング・市場ニュースは trade に残っている。

## 開示の自動追加

平日の夜に定期実行で、新しい開示を読んで `コード_開示.md` に分析を書き足す（大きな開示なら `コード_基礎.md` も直す）。
手順は [`CLAUDE.md`](CLAUDE.md)、道具は `tools/disclosures.py`、データは `data/コード/`。

※ 数字は開示資料から。PER・シナリオは私の推定で、投資判断は自分で。
